# Sleep Rework Reborn

You can only sleep once you're tired. Tiredness builds up while you're awake, sleeping resets it, and players who stay up far too long get hunted by phantoms. Two new potions, Liveliness and Drowsiness, slow it down or speed it up.

Port of [Sleep Rework](https://github.com/Lemonszz/SleepRework) by Lemonszz to Minecraft 1.21.1, for NeoForge and Fabric.

## Building

`./gradlew buildAll` builds both loaders and runs the game tests.
